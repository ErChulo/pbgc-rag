    Capability and release status

      Official artifacts, approved actuarial rules, semantic inference, SQL, graph queries and binary document parsing are unavailable in this build. Official field validation requires the approved dictionary. No official output can be released.

      Search guide

      Keyword search

      Enter words from a source. Each word must occur in a result. Search does not change the source.

      Exact phrase

      Select Exact phrase to find adjacent text. Search ignores letter case.

      Evidence locations

      Each result retains its source name, SHA-256 hash and parser locator. A text line is not a PDF page. Read the original source before you use a result.

      Keep your work

      Export a case before you close the browser. Local storage may be unavailable, cleared or tied to this file location. Restore verifies original bytes and rebuilds the parsed records.

      Unavailable tools

      Regex, SQL, graph search and local semantic models are not enabled here. Official templates and approved rules must be supplied and validated before official artifacts can be generated.
