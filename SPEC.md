# Implemented scope and required target

`KICKOFF.md` defines the full required system. This document distinguishes current implementation from that target. Version 0.1 is a development increment, not a completed or approved product.

## Current contracts

- Browser entry: `index.html`, classic local scripts and styles, strict CSP, no runtime installation or network dependency.
- Isolated cases: schema version 1 with content-addressed original sources, parsed evidence, proposed graph links, rule proposals, and synthetic calculation traces.
- Text ingestion: TXT, Markdown, CSV, TSV, JSON, XML text nodes, and HTML inert text. Original bytes retained; UTF-8 and BOM UTF-16 supported. 16 MiB per source. Locators address exact decoded source positions, JSON pointers, or source paths; no invented PDF coordinates.
- Search: case-scoped keywords, case-insensitive exact text, bounded nonbacktracking regex, scalar SELECT subset, and bounded typed temporal graph API. Semantic inference is unavailable; deterministic search remains usable.
- Portable packages: schema and SHA-256 envelope plus source-byte hashes checked on import/export. Integrity is not authentication or truth validation.
- Review: versioned proposals, explicit human approval metadata at API level, exact rational synthetic accrual arithmetic with independent regression values. No actual plan rule or statutory interpretation is activated.
- Reports: internal evidence-linked review and explicitly provisional BSRS internal representation. All official release is blocked.

## Full target still required

Complete binary format coverage, advanced local inference, incremental large-file indexing and worker cancellation, reference-library lifecycle, domain ontology and temporal conflict adjudication, official data dictionary validation, authoritative actuarial functions, approved template-preserving artifact generation, enterprise browser acceptance, resource/performance acceptance, and full synthetic end-to-end official acceptance remain required. A supported subset must never be labeled full format or actuarial compliance.

Subsequent integrated increments add bounded DOCX/XLSX/XLSM, standard-font PDF and standalone SQLite support, measured IndexedDB checkpoints with memory fallback, source-linked standalone internal HTML layouts, and optional typed claims with unresolved overlap screening. See README.md for exact unsupported format variants and ACCEPTANCE.md for test evidence. These additions do not satisfy the full target above.
